# ESCAPE

A small 2D stealth prison-escape game built as a personal game-development project.

The goal is simple: get inside the prison, avoid the guards, collect the items you need, unlock the exit, and escape without getting caught.

🎮 **Play ESCAPE:** 
    https://escape-bice-nine.vercel.app/

## Current Features

* 2D top-down prison map
* Player movement with WASD / Arrow Keys
* Wall collision
* Moving guards
* Guard vision and line of sight
* Smoke bomb mechanic
* Guards can be put to sleep
* Key collection
* Locked gate
* Level completion screen
* Caught / Game Over screen
* Try Again / level restart
* Mission briefing before the level starts

## Controls

* **WASD / Arrow Keys** — Move
* **E** — Interact / Pick up items
* **Q** — Use smoke bomb

## Level 01

The first level currently follows this basic mission:

1. Find the smoke bomb.
2. Use it to disable the guards.
3. Find the key.
4. Reach the locked gate.
5. Escape the prison.
